# Weno Server OS, an open source painless cloud runtime.

Now with Server OS, you no longer have to rent a server to host your platform and files.

## How to run Server OS build workflow

Unlike traditional repos that use GitHub Actions, Weno Server OS repository requires you to make a new release starting with 'v', for example to make a new v1.0.0 release:

```sh
git tag v1.0.0
git push origin v1.0.0
```
